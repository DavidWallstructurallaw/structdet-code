# Change history

## 0.1.0

C06 makes the existing C01-C05 analysis available as a qualified installed CLI.
The wheel includes both task packs and 58 owned example files. New `examples`
and `demo` commands export passive inputs or run and replay six complete
demonstrations outside a source checkout. The original developer demo command
delegates to the same implementation.

The release includes passive source preparation, bounded sorting/graph rules,
source-bound review import, compatible condition comparison, recorded revision
trajectories, checkpoint cohorts, interventions, finite failure profiles and
exact JSON/Markdown replay. Source and wheel installation routes are qualified
on Linux with CPython 3.12.14, with no third-party runtime dependencies.

Installation, input preparation, interpretation, related-work and release guides
are included. Distribution metadata records the repository URLs, scoped topics
and combined Apache-2.0 / CC-BY-4.0 license expression. Both license texts and
attribution notices ship with the artifacts; theory PDFs are excluded.

Record schemas, task boundaries and operative recognition rules are unchanged
from dev5. Software identity changes with 0.1.0, so dev5 snapshots require dev5;
create fresh snapshots for the installed 0.1.0 environment.

Known limits: narrow task/rule coverage, supplied provenance not authenticated,
no model calls or candidate execution, no provider log adapters, no causal or
independence inference, no fitted half-life or external recovery estimate, and
no qualification of other operating systems or Python versions.

  Interventions preserve ancestor anchors, event order, feedback receipt links,

  byte matches. Withheld events stay withheld. No causal effect, autonomous
  discovery, source independence or external recovery estimate is inferred.

  rosters. Compatible pairs show shared failures, distinct observed failures and
  failures opposite unobserved outcomes. Selection, conformance, scope, repeated

  preserves older assignments and source/revision records; old dependent designs
  fail against the corrected study, while captured historical results still replay.
- New snapshot/replay commands for inspect, trace and compare. Bundles capture
  exact passive input bytes and both report formats. Replay checks the installed
  method/software/runtime identity and recomputes JSON and Markdown exactly.
  It executes no bundled software, model, candidate or arbitrary hook.
- A two-run intervention example, a six-demonstration user runner, the C05 guide,
  current reports and retained historical C01-C04 verification.

### Intervention and profile outcomes

Both runs follow RELAX, FIFO, RELAX. The last class is observed_again. I1 records
a copied reference; its captured reference bytes equal the final artifact.
I2 records an alternative instruction and a withheld reference with identical
final bytes. The withheld event's agent_visible_association is false. All
autonomous-discovery and causal flags remain false and external recovery remains
not_estimated. Several events precede the same artifact without extra generations.

The different bad RELAX and FIFO sources share six failed inputs:
T04, T05, T06, T07, T08 and T10. Their comparison has ten jointly completed cases,
six shared failures and no distinct failures. Against the corrected source those
six are failed-versus-passed observations. A partial-profile test removes T04/T05
from the opposite completed set and retains them as failures_other_unobserved,
without treating them as successes or distinct robustness.

Direct fault cases exercise foreign/descendant anchors, contradictory event
order, missing materials, feedback/exposure contradictions, uncaptured material,
unverified independence claims, excluded paths and unresolved assignments.
Profiles reject incomplete/duplicate case rosters and inconsistent receipt counts.
Changed environment, visibility and execution basis prevent inappropriate pairing.
Material tampering and symlinks fail; private prompt/program content stays out of
JSON/Markdown reports, and passive canaries remain unexecuted.

### Replay and correction outcomes

All three analysis actions reproduce saved bytes. A moved bundle replays after
its original input directory is deleted. Raw byte tampering fails before
recomputation; updating an inventory hash alone still fails the study binding.
Rehashed changes to a result, report or event remain detectable by recomputation.
Method, version, interpreter, platform and package-code identity mismatches fail.

The replay tests also reject path traversal, symlinks, duplicate inventory,
unknown actions/hooks, absent results, malformed/nonfinite JSON and excessive
file sizes/counts. An unlisted source present in the original directory cannot
satisfy a replay reference. Snapshot creation refuses existing outputs and
validates captured inputs before persistent output is created. Files/directories
have owner-only permissions in the qualified environment.

The integrated correction starts with passive sorting preparation. It withdraws
one admitted assignment into unresolved, reducing the admitted population by one
while preserving all source artifacts and revision records. Existing trace,
comparison and evidence bindings fail against the corrected manifest. The old
snapshot still reproduces the old manifest; fresh templates and a new snapshot
reproduce the correction. No history or old result is silently rewritten.

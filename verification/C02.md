## Observable static result

The seven source files in `examples/static` are copied from the project-owned
C01 sources. Six rule-qualified observations give INS=4, MERGE=1, SEL=1, support=3,
SCI=1/2, Gini-Simpson=1/2. One opaque implementation remains unresolved.
All seven validity states are not_assessed because this newly prepared collection
has no receipts. Its valid-classified population is empty with undefined SCI.
The original C01 example retains its separate finite execution receipts and labels.

Tests preserve the separation between classification and correctness, verify
whole-body matching instead of partial-feature admission, and ensure exact rule
claims are recomputed rather than trusted from a manifest. They also exercise
source/task/study/review binding, correction withdrawal, missing decisions,
symlinks/traversal, source/scan/parser limits, source non-execution, bounded errors,
no-overwrite behavior and legacy/new schema separation.

## Limits and next increment

Recognition covers nine explicit structural variants, not every implementation
of eight families. Uncovered programs can use supplied human review; AI proposals
stay unadmitted. The software does not authenticate reviewers, origin claims or
test execution, and does not execute imported code.

No wheel/install qualification, additional platform matrix, provider adapter,
live coding-agent experiment, package publication, tag or Release was performed.
The source candidate is intended for a C02 development branch and pull request;
merge authorization is separate. Main remains the accepted C01 baseline until
that merge is authorized and performed.

Next: C03 adds the bounded graph task and compatible-condition comparisons.
C04 still includes the required individual and multi-run revision analysis.

## Reproduction

```bash
python3 -m unittest discover -s tests -v
python3 -m structdet_code validate --study examples/static/study.json
python3 -m structdet_code inspect --study examples/static/study.json --format markdown
python3 -m structdet_code inspect --study examples/static/study.json --format json
python3 tools/check_bench_parity.py --bench-root /absolute/path/to/trusted/structdet-bench
```

The optional parity command requires the exact trusted Bench source modules
identified by `tools/check_bench_parity.py`; it is not an untrusted-code adapter.
